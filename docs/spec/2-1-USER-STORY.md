# 2-1 유저 스토리

기준: [배경](1-BACKGROUND.md).

<br>

### 2-1-1 사용자 목표

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| BOJP-US-001 | 문제를 맞힌 사용자 | 채점 현황 페이지에서 내 기록의 실행 시간과 메모리가 다른 정답 제출 사이에서 어느 위치인지 그래프와 상위 비율로 보고 싶다 | 더 최적화할 여지가 있는지 판단하고 싶다 |
| BOJP-US-002 | 특정 언어로 푼 사용자 | 언어 필터를 고르지 않아도 내가 푼 언어로 낸 정답 제출 안에서 내 위치를 보고 싶다<br>여러 언어로 풀었으면 다른 언어 기준으로 바로 바꿔 보고 싶다 | 언어마다 실행 시간과 메모리 차이가 커서 다른 언어와 섞어 비교하면 의미가 없다 |
| BOJP-US-003 | 어두운 테마를 쓰는 사용자 | 성능 카드가 쓰고 있는 BOJ 테마와 같은 밝기로 보이면 좋겠다 | 어두운 페이지에서 밝은 카드만 튀지 않았으면 한다 |
| BOJP-US-004 | 서로 다른 값이 많은 문제를 보는 사용자 | 분포 그래프의 모양과 내 위치를 한눈에 읽고 싶다 | 값마다 막대를 두면 막대가 빽빽해 읽기 어렵다 |
