BOJP-QA-044, BOJP-QA-045는 자동 테스트(`node --test`)이고 테스트 이름에 ID가 있다. 랜딩과 Firefox 제출이 같은 함수를 쓴다. BOJP-QA-046은 랜딩 폴더를 로컬 정적 서버로 연 브라우저에서 확인한다. BOJ에 요청하지 않는다.

| ID | 입력이나 사전조건 | 절차 | 기대 결과 |
|---|---|---|---|
| BOJP-QA-044 | `### Internal` 절이 처음, 중간, 끝에 있는 노트<br>저장소의 모든 버전별 노트 파일 | Internal 거르기 | `### Internal`부터 다음 제목 전까지만 빠짐<br>다른 절과 순서는 그대로 |
| BOJP-QA-045 | 제목(`#`~`######`), `- `와 `* ` 목록, 빈 줄, HTML 태그가 든 줄, Internal 절이 섞인 본문 | 본문을 블록으로 나눔 | 제목, 이어진 목록 항목을 묶은 목록, 문단 순서의 글자 블록<br>HTML 태그 줄은 글자 그대로 문단<br>Internal 절 없음 |
| BOJP-QA-046 | GitHub Release가 있음 | 밝은 모드와 어두운 모드에서 랜딩을 엶<br>같은 탭에서 새로 고침<br>`sessionStorage`를 비우고 `fetch`를 실패시켜 다시 불러옴 | 최근 Release 3개, 최신만 펼침, Internal 절 없음, 색 모드에 맞는 색<br>새로 고침 뒤 GitHub API 요청 없음<br>실패 문구와 GitHub 릴리스 페이지 링크 |
