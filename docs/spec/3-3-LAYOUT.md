### 3-3-1 배치

화면 예시는 [밝은 테마](../../landing/assets/screenshot.png)와 [어두운 테마](../screenshot-theme-dark.png)다.

| 영역 | 표현 |
|---|---|
| 위치 | 채점 현황 결과 표 바로 위 |
| 성능 카드 묶음 | 너비 100%, 최대 900px<br>가운데 정렬, 아래 여백 20px<br>운영체제 기본 글꼴 |
| 비교 언어 줄 | 성능 카드 묶음 맨 위, 카드 줄 위<br>아래 여백 8px |
| 카드 줄 | 두 카드를 가로로 놓고 간격 20px<br>두 카드는 같은 너비<br>페이지 너비와 관계없이 한 줄 |
| 카드 | 모서리 반경 10px, 안쪽 여백 위아래 20px, 좌우 24px<br>1px 테두리<br>그림자 `0 1px 4px rgba(0, 0, 0, 0.08)`<br>최소 높이 240px |
| 카드 머리 | 위에서부터 지표 이름, 큰 숫자, 보조 줄 |
| 그래프 영역 | 카드 아래쪽에 붙임<br>카드 너비, 높이 120px |

### 3-3-2 상태별 표시

| 상태 | 큰 숫자 | 보조 줄 | 그래프 영역 |
|---|---|---|---|
| 분석 중 | 없음 | "분석 중..." | 비어 있음 |
| 데이터 부족 | 없음 | 빨간 글자 "데이터 부족" | 비어 있음 |
| 결과 | 실행 시간 `{값} ms`<br>메모리 `{값} KB` | `상위 {비율}%`와 안내 아이콘 | 분포 막대 |

<br>

### 3-3-3 글자와 문구

| 요소 | 글자 | 문구 |
|---|---|---|
| 비교 언어 줄 | 13px | `{언어 이름} 기준`<br>모든 언어로 비교하면 `모든 언어 기준`<br>다른 언어가 있으면 이어서 ` · 다른 언어 ` 뒤에 언어 이름 링크를 `, `로 이음 |
| 지표 이름 | 14px, 굵기 600 | "실행 시간", "메모리" |
| 큰 숫자 | 26px, 굵기 700 | 3-3-2의 결과 문구 |
| 보조 줄 | 13px | 3-3-2의 상태 문구 |
| 상위 비율 | 보조 줄 안에서 굵게, 파란색 | `{비율}%` |
| 안내 아이콘 | 14px 원형 정보 아이콘<br>보조 줄의 상위 비율 오른쪽 | 없음 |
| 안내 툴팁 | 11px, 가운데 정렬<br>안내 아이콘 오른쪽에 화살표와 함께 표시<br>마우스를 올리거나 키보드 초점을 받으면 0.2초 동안 나타남 | `최근 {n}건의 제출 기준`<br>n은 하늘색<br>언어는 비교 언어 줄에만 보임 |
| 막대 툴팁 | 그래프 기본 | ` {막대 이름} · {제출 수}건`<br>제목 줄 없음 |
| 막대 이름 | 막대 툴팁 안 | 값마다 막대이면 `{값}{단위}`. 예: `40ms`<br>구간이면 `{시작}–{끝}{단위}`. 예: `40–49ms`<br>맨 오른쪽 막대이면 `≥ {경계}{단위}`. 예: `≥ 820ms`<br>단위는 실행 시간 `ms`, 메모리 `KB` |

<br>

### 3-3-4 그래프

| 항목 | 표현 |
|---|---|
| 모양 | 세로 막대 |
| 가로축 | 막대([2-2-2](2-2-REQUIREMENTS.md#2-2-2-성능-위치)의 값이나 구간)마다 한 칸<br>값 사이의 차이와 관계없이 칸 너비가 같음 |
| 가로축 라벨 | 값이나 구간 시작 값. 실행 시간 `{값}ms`, 메모리 `{값}KB`<br>맨 오른쪽 막대는 `≥ {경계}{단위}`<br>10px, 회전 없음<br>최대 6개만 보이고 나머지는 건너뜀 |
| 세로축 | 숨김 |
| 격자, 축선, 범례 | 없음 |
| 막대 | 칸 너비의 70%<br>모서리 반경 2px<br>제출 수가 적어도 최소 길이 5px<br>제출이 없는 구간은 막대 없이 칸만 둠 |
| 내 값 막대 | 내 값이 든 막대. 다른 막대와 다른 색 |

### 3-3-6 접근 가능한 이름

요구사항은 [2-2-7](2-2-REQUIREMENTS.md#2-2-7-접근성)에 있다. `{지표}`는 "실행 시간" 또는 "메모리", `{단위}`는 실행 시간 `ms`, 메모리 `KB`다.

| 요소 | 역할 | 이름 | 설명과 동작 |
|---|---|---|---|
| 안내 아이콘 | 버튼 | `{지표} 표본 안내`. 예: `실행 시간 표본 안내` | 설명은 안내 툴팁 문구 `최근 {n}건의 제출 기준`<br>초점 표시는 브라우저 기본 |
| 안내 아이콘 그림 | 숨김 | 없음 | 버튼 이름만 읽힘 |
| 안내 툴팁 | 툴팁 | 없음 | 3-3-3의 안내 툴팁 |
| 그래프 | 이미지 | `{지표} 분포, 내 기록 {값}{단위}, 상위 {비율}%, {비교 언어} 최근 {n}건 기준`<br>모든 언어로 비교하면 `{비교 언어}`는 `모든 언어`<br>예: `실행 시간 분포, 내 기록 57ms, 상위 76.92%, C++17 최근 78건 기준` | 다시 그릴 때마다 새 값 |
| 큰 숫자와 보조 줄 영역 | 알림 영역, `polite` | 없음 | 3-3-2의 상태 문구가 바뀌면 알림 |
