# 3-3 화면 배치

기준: [화면 흐름](3-2-INTERACTION-FLOWS.md), [화면 구성](3-1-INFORMATION-ARCHITECTURE.md).

<br>

### 3-3-1 배치

화면 예시는 [밝은 테마](../screenshot-theme-light.png)와 [어두운 테마](../screenshot-theme-dark.png)다.

| 영역 | 표현 |
|---|---|
| 위치 | 채점 현황 결과 표 바로 위 |
| 성능 카드 묶음 | 너비 100%, 최대 900px<br>가운데 정렬, 아래 여백 20px<br>운영체제 기본 글꼴 |
| 카드 줄 | 두 카드를 가로로 놓고 간격 20px<br>두 카드는 같은 너비<br>페이지 너비와 관계없이 한 줄 |
| 카드 | 모서리 반경 10px, 안쪽 여백 위아래 20px, 좌우 24px<br>1px 테두리<br>그림자 `0 1px 4px rgba(0, 0, 0, 0.08)`<br>최소 높이 240px |
| 카드 머리 | 위에서부터 지표 이름, 큰 숫자, 보조 줄 |
| 그래프 영역 | 카드 아래쪽에 붙임<br>카드 너비, 높이 120px |

<br>

### 3-3-2 상태별 표시

| 상태 | 큰 숫자 | 보조 줄 | 그래프 영역 |
|---|---|---|---|
| 분석 중 | 없음 | "분석 중..." | 비어 있음 |
| 데이터 부족 | 없음 | 빨간 글자 "데이터 부족" | 비어 있음 |
| 결과 | 실행 시간 `{값} ms`<br>메모리 `{값} KB` | `상위 {비율}%`와 안내 아이콘 | 분포 막대 |

<br>

### 3-3-3 글자와 문구

| 요소 | 글자 | 문구 |
|---|---|---|
| 지표 이름 | 14px, 굵기 600 | "실행 시간", "메모리" |
| 큰 숫자 | 26px, 굵기 700 | 3-3-2의 결과 문구 |
| 보조 줄 | 13px | 3-3-2의 상태 문구 |
| 상위 비율 | 보조 줄 안에서 굵게, 파란색 | `{비율}%` |
| 안내 아이콘 | 14px 원형 정보 아이콘<br>보조 줄의 상위 비율 오른쪽 | 없음 |
| 안내 툴팁 | 11px, 가운데 정렬<br>안내 아이콘 오른쪽에 화살표와 함께 표시<br>마우스를 올리면 0.2초 동안 나타남 | `채점 서버 {기준 채점 서버}, 최근 {n}건 기준`<br>채점 서버 값이 없으면 `최근 {n}건의 제출 기준`<br>언어 이름이 있으면 다음 줄에 `({언어 이름})`<br>n은 하늘색 |
| 막대 툴팁 제목 | 그래프 기본 | 막대의 가로축 라벨 |
| 막대 툴팁 내용 | 그래프 기본 | ` {제출 수}명` |

<br>

### 3-3-4 그래프

| 항목 | 표현 |
|---|---|
| 모양 | 세로 막대 |
| 가로축 | 표본의 값마다 한 칸<br>값 사이의 차이와 관계없이 칸 너비가 같음 |
| 가로축 라벨 | 실행 시간 `{값}ms`, 메모리 `{값}KB`<br>10px, 회전 없음<br>최대 6개만 보이고 나머지는 건너뜀 |
| 세로축 | 숨김 |
| 격자, 축선, 범례 | 없음 |
| 막대 | 칸 너비의 70%<br>모서리 반경 2px<br>제출 수가 적어도 최소 길이 5px |
| 내 값 막대 | 다른 막대와 다른 색 |
