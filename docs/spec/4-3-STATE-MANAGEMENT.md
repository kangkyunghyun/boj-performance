### 4-3-1 상태의 기준과 수명

상태는 모두 페이지의 메모리에만 있고 페이지를 떠나면 진행 중인 조회와 함께 사라진다.

| 상태 | 기준 | 정하는 시점 |
|---|---|---|
| 문제와 언어 | 현재 페이지 주소 | 진입할 때 한 번 |
| 로그인 아이디 | 현재 페이지의 로그인 표시 | 진입할 때 한 번 |
| 내 기록 | 내 기록 요청 응답 | 내 기록 조회가 끝날 때<br>이후 바뀌지 않음 |
| 표본 | 표본 요청 응답을 읽은 순서대로 쌓은 목록 | 표본 조회가 끝날 때 확정 |
| 분포와 상위 비율 | 내 기록과 확정된 표본 | 표본 확정 직후 지표별로 한 번 |
| 카드 색 | 테마 판정 | 성능 카드를 끼워 넣을 때 |
| 막대, 가로축, 막대 툴팁 색 | 테마 판정 | 그래프를 그릴 때 |
| 그래프 | 지표마다 하나 | 같은 지표를 다시 그리면 이전 그래프를 파기한 뒤 새로 그림 |
