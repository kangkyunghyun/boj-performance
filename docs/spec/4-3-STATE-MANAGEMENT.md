### 4-3-1 상태의 기준과 수명

표본을 뺀 상태는 페이지의 메모리에만 있고 페이지를 떠나면 진행 중인 조회와 함께 사라진다. 표본은 [4-3-2](#4-3-2-세션-저장소)대로 탭의 세션 저장소에도 둔다.

| 상태 | 기준 | 정하는 시점 |
|---|---|---|
| 문제와 언어 | 현재 페이지 주소 | 진입할 때 한 번 |
| 로그인 아이디 | 현재 페이지의 로그인 표시 | 진입할 때 한 번 |
| 내 기록 | 내 기록 요청 응답 | 내 기록 조회가 끝날 때<br>이후 바뀌지 않음 |
| 표본 | 표본 요청 응답을 읽은 순서대로 쌓은 목록<br>저장한 표본이 있으면 그 앞에 새 행을 붙인 목록 | 저장한 표본이 없으면 첫 페이지를 읽을 때와 표본 조회가 끝날 때<br>있으면 성능 카드를 끼워 넣은 직후와 새 행이 있는 표본 조회가 끝날 때 |
| 분포와 상위 비율 | 내 기록과 그 시점의 표본 | 표본을 정할 때마다 지표별로 한 번 |
| 카드 색 | 테마 판정 | 성능 카드를 끼워 넣을 때 |
| 막대, 가로축, 막대 툴팁 색 | 테마 판정 | 그래프를 그릴 때 |
| 그래프 | 지표마다 하나 | 같은 지표를 다시 그리면 이전 그래프를 파기한 뒤 새로 그림 |

<br>

### 4-3-2 세션 저장소

표본은 BOJ 페이지 출처의 `sessionStorage`에 둔다. 확장 저장소(`chrome.storage`)는 쓰지 않는다.

| 항목 | 규칙 |
|---|---|
| 키 | `boj-performance:v1:{문제}:{언어}`<br>`{언어}`는 `language_id`, 없으면 빈 값 |
| 값 | JSON `{ "rows": [[제출 번호, 시간, 메모리], ...], "savedAt": 저장 시각(ms) }`<br>`rows`는 제출 번호 내림차순, 최대 200행 |
| 수명 | 그 탭의 세션<br>새로 고침, 같은 탭의 페이지 이동에서는 남고 탭을 닫으면 사라짐<br>새 탭은 저장한 표본 없이 시작 |
| 복원 | 성능 카드를 끼워 넣은 직후 한 번 읽음 |
| 깨진 값 | JSON이 아니거나, `rows`가 비었거나, 행이 정수 3개가 아니거나, 제출 번호가 내림차순이 아니면 그 키를 지우고 저장한 표본 없이 동작 |
| 저장 | 표본 조회가 예외 없이 끝나고 표본이 바뀌었을 때 키 전체를 덮어씀<br>표본이 0건이면 쓰지 않음<br>요청 예외가 있었으면 쓰지도 지우지도 않음 |
| 읽기, 쓰기 예외 | 용량 초과나 차단으로 생긴 예외는 무시하고 저장한 표본 없이 동작 |
