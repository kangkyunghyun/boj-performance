# DECISIONS

현재 적용 기준은 각 명세에 두고 결정 당시의 내용과 대체 관계는 이 문서에 기록한다.

<br>

### 1 기록 규칙

- 결정 하나를 표 하나로 기록한다. 추가만 하고 지우지 않는다.
- 근거는 커밋이다. 커밋 메시지와 변경 내용에서 확인되지 않는 항목은 행을 두지 않는다.
- 결정이 바뀌면 새 ID로 기록하고 대체 관계를 적는다.

<a id="d-013"></a>

**D-013. 같은 채점 서버의 제출끼리 비교**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-21 |
| 상태 | 적용됨 |
| 배경 | BOJ 재개 뒤 채점 서버가 `1`(AWS), `2`(GCP) 둘이다. BOJ는 결과 표의 채점 서버 셀에 "세대가 달라 실행 시간은 직접 비교되지 않습니다"라고 안내한다.<br>2026-11-21 34558번 최근 정답 제출 20건 가운데 서버 `1`이 17건, `2`가 3건이었다. |
| 채택 | 내 정답 제출 첫 페이지의 가장 최근 정답 제출의 채점 서버를 기준으로 삼는다.<br>내 기록은 그 서버 제출 가운데 고르고 표본은 그 서버 제출만 남긴다. 요청 수는 그대로다.<br>채점 서버 값을 읽지 못하면 거르지 않는다.<br>안내 툴팁에 채점 서버를 보인다. |
| 이전 동작 | 채점 서버를 보지 않고 모든 정답 제출을 한 표본으로 씀 |
| 근거 | [7cf6061](https://github.com/kangkyunghyun/boj-performance/commit/7cf6061), 이슈 #2 |
