# 1 배경

<br>

### 1-1 사용자와 목적

백준 온라인 저지(BOJ)에서 문제를 맞힌 사용자는 채점 현황 페이지에서 제출마다 실행 시간과 메모리를 본다. BOJ는 내 기록이 다른 정답 제출 사이에서 어느 위치인지 보여 주지 않는다. 사용자는 목록을 넘기며 직접 비교해야 한다. BOJ Performance는 채점 현황 페이지 안에 내 기록의 위치를 분포 그래프와 상위 비율로 보여 준다. 별도 서버 없이 사용자의 브라우저에서 BOJ 페이지를 읽어 계산한다.

| 범위 | 책임 |
|---|---|
| BOJ Performance | 채점 현황 페이지 판별<br>내 기록과 표본 조회<br>분포와 상위 비율 계산<br>성능 카드 표시 |
| BOJ | 로그인, 채점 결과, 채점 현황 페이지와 언어 필터 |
| boj-extended | 사용자가 고른 BOJ 테마<br>BOJ Performance는 이 설정을 읽기만 함 |

<br>

### 1-2 용어

| 용어 | 의미 |
|---|---|
| 채점 현황 페이지 | BOJ의 `/status` 페이지<br>문제, 사용자, 결과, 언어로 제출을 거름 |
| 정답 제출 | 결과가 "맞았습니다!!"인 제출 |
| 내 기록 | 로그인한 사용자의 정답 제출 가운데 비교에 쓰는 제출 하나 |
| 표본 | 비교 대상이 되는 그 문제의 최근 정답 제출 묶음 |
| 상위 비율 | 표본 안에서 내 기록의 순위를 백분율로 나타낸 값<br>작을수록 좋음 |
| 언어 필터 | 채점 현황 페이지의 언어 선택 |
| 성능 카드 | 채점 현황 페이지에 끼워 넣는 실행 시간 카드와 메모리 카드 |
