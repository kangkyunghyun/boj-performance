# 2-2 요구사항

기준: [사용자 목표](2-1-USER-STORY.md).

<br>

### 2-2-1 적용 범위

| 항목 | 범위 |
|---|---|
| 브라우저 | Chrome, Whale, Firefox |
| 페이지 | 문제를 지정한 채점 현황 페이지<br>대회의 채점 현황 페이지는 제외 |
| 사용자 | BOJ에 로그인했고 그 문제의 정답 제출이 있는 사용자<br>언어 필터가 있으면 그 언어의 정답 제출이 있어야 함 |
| 표시 언어 | 한국어 |

<br>

### 2-2-2 성능 위치

BOJP-US-001.

| 조건 | 요구사항 |
|---|---|
| 내 기록 | 내 정답 제출 목록 첫 페이지(최신 20건)에서 실행 시간이 가장 짧은 제출<br>실행 시간이 같으면 메모리가 적은 제출 |
| 메모리의 내 값 | 실행 시간 기준으로 고른 같은 제출의 메모리 |
| 표본 | 그 문제의 정답 제출을 최신순으로 최대 10페이지(최대 200건) |
| 다시 볼 때 | 같은 탭에서 같은 문제와 언어의 표본을 받은 적이 있으면 그 표본으로 먼저 보임<br>그 뒤 새 정답 제출만 받아 앞에 붙이고 최신 200건으로 자름 |
| 지표 | 실행 시간(ms)과 메모리(KB)를 따로 계산하고 따로 보임 |
| 상위 비율 | 표본에서 내 값보다 작은 제출 수를 a, 표본 크기를 n이라 할 때 (a + 1) ÷ n × 100<br>100을 넘으면 100<br>소수점 둘째 자리까지 |
| 같은 값 | 내 값과 같은 제출은 a에 넣지 않음 |
| 분포 | 표본의 값마다 제출 수를 세어 값 오름차순 막대로 보임<br>내 값의 막대를 다른 막대와 다른 색으로 강조 |
| 표본 밖의 내 기록 | 내 값이 표본에 없으면 그 값의 막대를 1건으로 더해 강조 막대가 늘 보이게 함<br>상위 비율의 n에는 더하지 않음 |
| 표본 크기 표시 | 상위 비율 옆 안내에 n을 보임 |

<br>

### 2-2-3 언어별 비교

BOJP-US-002.

| 조건 | 요구사항 |
|---|---|
| 언어 필터 있음 | 내 기록과 표본을 모두 그 언어의 제출로 한정<br>표본 크기 안내에 언어 이름을 함께 보임 |
| 언어 필터 없음 | 모든 언어의 제출 |
| 언어 변경 | 사용자가 언어를 바꿔 검색해 페이지가 다시 열리면 새 언어로 다시 계산 |

<br>

### 2-2-4 테마

BOJP-US-003.

| 조건 | 요구사항 |
|---|---|
| boj-extended 테마가 어두움 | 어두운 색 |
| boj-extended 테마가 밝음 | 밝은 색 |
| boj-extended 테마 설정 없음 | 브라우저와 OS의 색 모드 설정 |
| 적용 시점 | 페이지를 열 때 한 번<br>페이지를 연 뒤 바꾼 테마는 다음에 페이지를 열 때 반영 |

<br>

### 2-2-5 실패와 복구

| 조건 | 결과 |
|---|---|
| 적용 범위 밖, 로그인하지 않음, 내 정답 제출 없음, 내 기록 조회 실패 | 아무것도 표시하지 않고 BOJ 페이지를 바꾸지 않음 |
| 표본이 0건 | 두 카드에 "데이터 부족" |
| 표본 조회가 중간에 실패 | 실패 전에 받은 표본으로 계산<br>그 표본은 저장하지 않음 |
| 저장한 표본으로 보인 뒤 새 정답 제출 조회가 실패 | 저장한 표본으로 보인 결과를 그대로 둠<br>저장한 표본을 지우지 않음 |
| 세션 저장소를 읽거나 쓸 수 없음 | 저장한 표본 없이 동작 |
| 다시 시도 | 자동 재시도 없음<br>사용자가 페이지를 새로 고치면 다시 조회 |

<br>

### 2-2-6 품질 제약

| 항목 | 기준 |
|---|---|
| BOJ 요청 수 | 페이지를 한 번 열 때 최대 11회<br>내 기록 1회, 표본 10회<br>같은 탭에서 다시 볼 때 새 정답 제출이 첫 페이지 안에 있으면 2회<br>내 기록 1회, 표본 첫 페이지 1회 |
| 요청 동시성 | 한 번에 하나씩 |
| 요청 대상 | BOJ만<br>다른 서버로 데이터를 보내지 않음 |
| 저장 | 표본만 탭의 세션 저장소에 둠. 탭을 닫으면 사라짐<br>내 기록과 계산 결과는 저장하지 않음 |
| BOJ 화면 | 결과 표 위에 성능 카드만 더하고 BOJ의 기존 요소를 바꾸지 않음 |
