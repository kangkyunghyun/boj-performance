# 3-1 화면 구성

기준: [요구사항](2-2-REQUIREMENTS.md).

<br>

### 3-1-1 화면과 진입 조건

화면은 채점 현황 페이지에 끼워 넣는 성능 카드뿐이다. 확장 자체의 팝업이나 설정 화면은 없다.

| 항목 | 조건 |
|---|---|
| 주소 | `https://acmicpc.net/status` |
| 표시 | 쿼리에 `problem_id`가 있음<br>쿼리에 `contest_id`가 없음<br>로그인함<br>내 기록이 있음 |
| 계산에 쓰는 쿼리 | `problem_id`, `language_id` |
| 계산에 쓰지 않는 쿼리 | 페이지의 `user_id`, `result_id` 같은 다른 거름 조건<br>다른 사람의 제출만 거른 페이지에서도 내 기록과 전체 표본으로 계산 |

<br>

### 3-1-2 정보 우선순위

실행 시간 카드를 왼쪽, 메모리 카드를 오른쪽에 둔다. 두 카드는 같은 순서로 정보를 보인다.

| 순서 | 정보 |
|---|---|
| 1 | 지표 이름 |
| 2 | 내 값과 단위 |
| 3 | 상위 비율 |
| 4 | 표본 크기와 언어 이름<br>안내 아이콘의 툴팁 |
| 5 | 분포 그래프 |
