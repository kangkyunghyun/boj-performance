### Features

- 언어 필터를 고르지 않고 채점 현황을 열면 모든 언어를 섞지 않고 내가 가장 최근에 맞은 제출의 언어로 비교합니다. 카드 위에 비교 언어가 보이고, 다른 언어로도 맞았다면 그 언어로 바로 바꾸는 링크가 생깁니다
- 같은 탭에서 같은 문제를 다시 열거나 결과 표의 다음 페이지로 넘기면 앞서 받은 기록으로 바로 보여주고, 그 사이 새로 생긴 제출만 받아 붙입니다
- 서로 다른 값이 많은 문제는 분포를 구간으로 묶어 막대가 빽빽하지 않게 보여줍니다. 내 값이 든 구간이 강조되고 상위 비율은 묶기 전 값으로 계산합니다
- 키보드(Tab)로 안내 아이콘에 가면 표본 안내가 보이고, 화면 낭독기가 그래프의 내 기록과 상위 비율, 표본 크기를 읽습니다

### Fixes

- 백준 주소가 `acmicpc.net`으로 바뀐 뒤 카드가 보이지 않던 문제를 고쳤습니다
- 막대에 마우스를 올리면 제출 수가 `명`으로 보이던 것을 `건`으로 고쳤습니다. 같은 사람의 제출도 따로 셉니다

### Internal

- 버전 태그로 GitHub Release와 zip을 만들고 Chrome 웹 스토어와 Firefox Add-ons 제출을 자동화
- Firefox용 manifest를 따로 고치지 않도록 확장 ID와 최소 버전을 manifest에 넣음
- 이슈 제목을 커밋 형식으로 통일
