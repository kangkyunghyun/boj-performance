### Features

- 채점 현황의 언어 필터를 그대로 따릅니다. "모든 언어"면 모든 언어의 정답 제출과 비교하고, 언어를 고르면 그 언어로 맞은 제출끼리 비교합니다. 카드 위의 비교 언어 줄은 없앴습니다
- 기록을 다 받을 때까지 카드에 회색 자리 표시를 보여 주고, 다 받은 뒤 한 번에 그립니다. 보이던 숫자가 중간에 바뀌지 않습니다

### Fixes

- 백준이 중간에 오류를 돌려줘도 일부만 받은 기록을 저장하지 않습니다. 같은 탭에서 다시 열었을 때 비교한 제출 수가 줄어든 채 남지 않습니다
- 주소의 언어 값에 따옴표가 섞여 있어도 카드가 보입니다

### Internal

- 요청 헤더를 바꾸던 규칙과 `declarativeNetRequest` 권한 제거
- 랜딩·다크 모드 스크린샷 갱신
- 스토어 설명에서 업데이트 섹션 제거, 커뮤니티 홍보글 원본과 작성 기준 갱신
- 오류 응답과 언어 필터 값 자동 테스트 추가
