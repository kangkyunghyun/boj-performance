# 1-2. 커뮤니티 홍보글

BOJ 게시판의 홍보 게시판 등에 올리는 글 원본이다.
스토어 설명은 [1-1-1](1-1-STORE-LISTING.md#1-1-1-한국어)이 맡고, 변경 이력은 [랜딩의 업데이트 소식](https://kangkyunghyun.github.io/boj-performance/)이 맡는다. 여기서 반복하지 않는다.

## 1-2-1 한국어

제목:

```text
채점 현황에서 내 코드가 몇 등쯤인지 보여주는 확장 프로그램을 만들었습니다
```

본문:

```text
문제를 맞히고 내 코드가 빠른 편인지 알고 싶을 때마다 채점 현황을 몇 페이지씩 넘기며 실행 시간과 메모리를 눈으로 비교해야 했습니다.
그래서 채점 현황 페이지 안에 내 기록이 다른 정답 제출 사이 어디쯤인지 그래프와 상위 비율로 보여주는 브라우저 확장 프로그램을 만들었습니다.
2026년 2월에 출시했고, Chrome, Whale, Firefox에서 쓸 수 있습니다.

- 로그인한 상태로 맞은 문제의 채점 현황을 열면 결과 표 위에 실행 시간·메모리 카드 두 개
- 최근 정답 제출 최대 200건의 분포 그래프에서 내 기록이 든 막대 강조
- "상위 15.20%"처럼 상위 비율과 비교한 제출 수 표시
- 같은 언어끼리 비교. 언어 필터를 고르지 않으면 가장 최근에 맞은 언어로, 다른 언어로도 맞았다면 링크 하나로 전환
- 서로 다른 값이 많은 문제는 구간으로 묶어 표시
- boj-extended 테마와 브라우저 다크 모드 지원

채점 현황 페이지를 브라우저에서 직접 읽어 계산하고, BOJ 말고 다른 서버로는 아무것도 보내지 않습니다.
BOJ에 부담을 주지 않도록 페이지를 한 번 열 때 요청을 최대 11번, 하나씩 보내고, 같은 탭에서 같은 문제를 다시 열면 새로 생긴 제출만 받습니다.
가입과 광고가 없고, 코드는 GitHub에 공개되어 있습니다.
https://github.com/kangkyunghyun/boj-performance

설치는 쓰시는 브라우저 링크에서 바로 하실 수 있습니다.
Chrome: https://chromewebstore.google.com/detail/boj-performance/bklabnmnfggmenngdnlndikconflcbij
Whale: https://store.whale.naver.com/detail/clhhbjiamhmgpehbmmacbppbiiijccpd
Firefox: https://addons.mozilla.org/ko/firefox/addon/boj-performance

휴대폰으로 보고 계신다면 아래 홈페이지를 PC에서 열어 주세요.
https://kangkyunghyun.github.io/boj-performance/

카드가 보이지 않거나 값이 이상한 문제가 있다면 댓글로 알려 주세요. 확인하는 대로 고치겠습니다.
```

## 1-2-2 갱신 절차

이 글은 스토어 설명이 아니라 게시글이다. 독자는 BOJ Performance를 처음 보고, 광고처럼 보이면 넘긴다. 작성 기준과 검증 명령은 [release-copy 스킬](../../.claude/skills/release-copy/SKILL.md)에 있다.

1. 버전별 변경 목록을 넣지 않는다. 계속 알릴 기능만 `-` 목록에 한 줄로 더한다.
2. 대괄호 섹션 제목, 리뷰·Star 요청 같은 스토어 문법을 넣지 않는다.
3. 목록 밖 문장은 `~습니다.`체다. 첫 문장은 독자가 겪는 불편이고, 첫 문단 안에서 이게 무엇인지 드러낸다.
4. 지표는 누구나 공개 페이지에서 확인할 수 있는 값만 쓴다. 평점은 평가 수가 적어 쓰지 않는다. "몇 개월째"처럼 시간이 지나면 틀리는 표현은 쓰지 않는다.

   | 숫자 | 세는 법 |
   |---|---|
   | 출시 시점 | 첫 릴리스의 연월. 첫 태그 날짜와 Firefox 부가 기능 등록일로 2026년 2월. 바뀌지 않는다 |
   | 사용자 수 | Chrome·웨일 스토어 페이지와 Firefox 부가 기능 페이지의 사용자 수를 더해 십 단위로 내리고 "N명 넘게"로 쓴다. 세 값 가운데 하나라도 확인하지 못하면 문장을 빼고 게시한다. 지금은 웨일 값을 확인하지 못해 빠져 있다 |

5. BOJ 부담 문장은 [2-2-6](../spec/2-2-REQUIREMENTS.md#2-2-6-품질-제약)의 요청 수와 같아야 한다. 요청 상한이 바뀌면 이 문장부터 고친다.
6. 홈페이지 링크는 랜딩이 공개된 뒤에만 남긴다. 공개 전에 게시하면 "휴대폰으로…" 두 줄을 빼고 게시한다.
