# 배포 문구

스토어 설명란과 커뮤니티 게시판에 붙여 넣는 문구 원본이다. 붙여 넣기와 게시는 사람이 한다.

작성 기준과 검증 명령은 [release-copy 스킬](../../.claude/skills/release-copy/SKILL.md)이 원본이며 여기서 반복하지 않는다.

| 문서 | 쓰는 곳 | 릴리스마다 |
|---|---|---|
| [1-1-STORE-LISTING.md](1-1-STORE-LISTING.md) | Chrome·Whale·Firefox 스토어 설명란 | `[vX.Y.Z 업데이트]` 섹션 교체 |
| [1-2-COMMUNITY-POST.md](1-2-COMMUNITY-POST.md) | BOJ 게시판 홍보 게시판 | 변경 목록 없음. 계속 알릴 기능만 목록에 한 줄, 출시·사용 지표 확인 |

변경 이력은 랜딩의 업데이트 소식이 GitHub Release에서 자동으로 맡는다. 두 문구가 버전 이력을 떠맡지 않는다.
