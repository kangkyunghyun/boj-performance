# 1-1. 스토어 설명

Chrome 웹 스토어, 웨일 스토어, Firefox Add-ons 설명란에 같은 글을 붙여 넣는다.
첫 문단에 검색어(백준, BOJ, 채점 현황, 실행 시간, 메모리)와 핵심 가치를 두고, 맨 아래 `[vX.Y.Z 업데이트]` 섹션만 릴리스마다 교체한다.

## 1-1-1 한국어

```text
백준 온라인 저지(BOJ) 채점 현황에서 내 코드의 실행 시간과 메모리가 다른 정답 제출 사이 어디쯤인지 그래프로 확인하세요.
BOJ Performance는 문제를 맞힌 사람을 위한 성능 비교 확장 프로그램입니다.

[주요 기능]
- 실행 시간(ms)과 메모리(KB) 분포를 막대 그래프로 보여주고 내 기록이 든 막대를 강조합니다.
- 최근 정답 제출 최대 200건 안에서 "상위 15.20%"처럼 내 기록의 상위 비율을 보여줍니다.
- 같은 언어끼리 비교합니다. 언어 필터를 고르지 않으면 내가 가장 최근에 맞은 언어로 비교하고, 다른 언어로도 맞았다면 카드 위 링크로 바꿀 수 있습니다.

[편의 기능]
- 서로 다른 값이 많은 문제는 분포를 구간으로 묶어 막대가 빽빽하지 않게 보여줍니다.
- 같은 탭에서 같은 문제를 다시 열면 앞서 받은 기록으로 바로 보여주고, 그 사이 새로 생긴 제출만 받아 붙입니다.
- boj-extended의 테마 설정을 따르고, 설정이 없으면 브라우저와 OS의 다크 모드를 따릅니다.
- 키보드와 화면 낭독기로도 내 기록, 상위 비율, 비교한 제출 수를 확인할 수 있습니다.

[사용 방법]
로그인한 상태로 내가 맞은 문제의 채점 현황(acmicpc.net/status?problem_id=…)을 열면 결과 표 위에 카드 두 개가 생깁니다.
가입과 광고가 없고, BOJ 말고 다른 서버로는 아무것도 보내지 않습니다.

[문의 및 기여]
버그 제보와 기능 제안은 GitHub Issues에서 받습니다.
홈페이지: https://kangkyunghyun.github.io/boj-performance/
GitHub: https://github.com/kangkyunghyun/boj-performance

도움이 되었다면 스토어 리뷰와 GitHub Star 부탁드립니다.

[v1.1.0 업데이트]
- 언어 필터를 고르지 않아도 모든 언어를 섞지 않고 내가 가장 최근에 맞은 언어로 비교합니다. 다른 언어로도 맞았다면 카드 위 링크로 바로 바꿀 수 있습니다.
- 같은 탭에서 같은 문제를 다시 열거나 결과 표의 다음 페이지로 넘기면 앞서 받은 기록으로 바로 보여줍니다.
- 서로 다른 값이 많은 문제는 분포를 구간으로 묶어 보여줍니다.
- 백준 주소가 acmicpc.net으로 바뀐 뒤 카드가 보이지 않던 문제를 고쳤습니다.
```

## 1-1-2 갱신 절차

1. 새 릴리스 노트(`docs/releases/vX.Y.Z.md`)로 맨 아래 `[vX.Y.Z 업데이트]` 섹션을 교체한다. 첫 문단은 릴리스와 무관하게 유지한다.
2. 업데이트 섹션은 다음 릴리스에서 사라진다. 계속 알릴 기능은 `[주요 기능]`이나 `[편의 기능]`으로 옮긴다.
3. 세 스토어 대시보드의 설명란에 붙여 넣는다. 사람이 한다.
